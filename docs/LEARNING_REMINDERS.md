# Local learning reminder phase 1
Opt-in in-app parent dashboard reminders, selected program scope, dated current-version skill reviews (up to three), daily optional reminder after selected local hour if no recorded practice today. Daily dismissal until next local day; no push, background scheduling, permissions or external calls. Existing profile-scoped storage behavior used; verify new dismissal key is included in profile scope before production. Daily reminder is not proof of inactivity because some local activities do not record dated evidence. No payment, quota or subscription notification until trusted live integration. Offline asset/server allowlist and tests added.
Phase 2: native Android generic daily local notification, explicit separate device-wide opt-in/disable, separate permission request (Android 13+), no exact alarm permission or networking. Inexact RTC_WAKEUP scheduled for next local hour, reschedules on boot and time/timezone change, skips late delivery outside selected hour. Force-stop, notification settings, device idle and OS restrictions can prevent delivery. State in no-backup AtomicFile, no child details. Browser panel hidden. In-app controls auto-save and daily dismissal now profile-scoped. Actual Android permission, boot, time-change and delivery behavior not yet tested on hardware; generic notification does not track practice completion and is separate from profile-specific in-app reminders. No subscription or quota alerts yet.
