# Local visual assessment pilot
24 draft multiple-choice questions covering the first foundation English unit (4 lessons) and first mathematics unit (4 lessons). Content is authored for this pilot and not educator-reviewed or official curriculum. Other lessons retain their current modes; do not imply universal question-bank coverage.
The question engine validates lesson references and option IDs, shuffles choices, accepts only the current question, calculates correctness from the immutable bank, and saves completed attempts only. No model output is accepted for grading. Browser storage keeps the last ten attempts per lesson, separate from oral repeat progress, legacy completion and mastery. Parent reset/history deletion includes visual results. Results do not unlock lessons or advance learning plans. Not a secure server assessment; local data can be altered by device users. Accessibility: text and icons, optional existing local speech; independent accessibility/educator review is still required.
The pilot adds no API traffic and works offline. Unit tests and Chromium offline smoke tests cover score calculation, invalid choices, duplicate results, bank references and persisted UI completion. Remaining: curriculum-wide reviewed content, richer item types, objective-specific skill graph, robust spoken evaluation and server authentication.

Follow-up: readiness probe uses Node HTTP and consumes response bodies to avoid the CI Undici parser assertion. Numeric repeat assessment now rejects negation, ambiguous phrases and arithmetic expressions instead of extracting a matching number; only exact number words/digits and a limited counting-noun allowlist are supported. Unsupported phrases are unresolved rather than incorrect. Handwriting quality must be a finite numeric score in the 0–100 range.
