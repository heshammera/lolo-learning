# Subject catalog milestone
Centralizes program and lesson listing, subject display and implemented activity capabilities. Existing 140 lesson IDs and curriculum version are unchanged. English and math use the existing dedicated implementations; unregistered subjects use generic cards only, with live voice, English writing and spoken-repeat modes disabled until explicit implementation. Draft or archived programs are excluded from the client catalog. This is not a server authorization or publication system.
Tests inject a synthetic science program with a unit and three lessons, and verify that the existing learning-path engine accepts it without subject-specific conditions. No science content is published to students by this milestone. The fixture is not a complete educator-reviewed curriculum, and server voice routing, CMS, capability-specific assessment and universal activity registry remain outstanding. Existing visual pilot quizzes are available from local practice and the protected parent tests view. All assets included in offline cache and Android bundle.
