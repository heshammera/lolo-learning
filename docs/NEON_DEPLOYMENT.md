## Read-only deployment gate
Vercel production builds with LOLO_USE_VERCEL_DATABASE=true execute scripts/verify_neon_build.sh. It checks all 26 tables, core family role permissions and expected projections using a read-only transaction, with bounded connect/query timeouts. No personal records or credentials are read into logs; no production fixtures or migrations are performed. It fails the build if the database cannot be validated, preserving the prior deployment. Preview builds skip this check. A passing gate is not an end-to-end family API or subscription test; keep live services disabled until separate validation.
