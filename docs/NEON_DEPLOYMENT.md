# Neon setup for LOLO Learning
Vercel has Marketplace-managed DATABASE_URL and POSTGRES_URL (secret values not needed). On the dedicated LOLO database, run database/bootstrap-neon.sql once in Neon SQL Editor (public schema, intended production branch; do not run on unrelated databases). Script applies existing reviewed migrations 001–015 inside one transaction and returns a count of 26 expected tables. No live payment or real voice consent is provisioned. Admin identity/CMS use separate admin-src migrations and a separate database; do not mix them here.
After review and CI, enable LOLO_USE_VERCEL_DATABASE=true in production only. Existing explicit LOLO_DATABASE_URL always wins; previews never implicitly use marketplace credentials. Prefer a separate least-privilege budget DB; on a small pilot, explicitly opt in to same DB with LOLO_BUDGET_USE_FAMILY_DB=true and set LOLO_SHARED_REQUEST_BUDGET=required only after testing. All family, sync, and staging feature flags remain disabled until separate production authorization, privacy review, and synthetic smoke tests. Do not expose migration endpoints or log credentials. DATABASE_URL is server-only.
