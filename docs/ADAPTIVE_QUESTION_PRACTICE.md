# Adaptive question practice pilot
Four authored draft lessons (hello-1, hello-2, math-found-count-1, math-found-count-2), 24 new questions, three levels and five unique items per session. Start at level two; a correct response raises target one level and an incorrect response lowers it, with nearest unused authored item if the target level is exhausted. Choice order randomized; completion is independently recalculated from original bank and level path. Fixed three-question assessment unchanged and version-separated; adaptive results are a different practice channel, not comparable evidence for mastery. Up to ten records per mode per lesson; active child profile checked before recording. Existing parent plan and progress unaffected. Offline browser regression and deterministic tests. Educator review and actual Android device QA pending. No AI generation or provider usage. This pilot is not full curriculum coverage or a calibrated ability estimate.
