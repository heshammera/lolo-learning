# Adaptive conversation guidance
Lesson-only coaching derived from up to the last three current-session recorded responses: first difficulty gives a gentle or guided hint (parent preference), second a simpler authored lesson example, third an optional break. A correct response resets the streak. No extra automatic provider call, no change to deterministic spoken-test questions or scores; completion/reward has priority. Tool responses carry a bounded instructional string only, never the learner transcript. A model-supplied answer is rejected unless a matching observed pending transcript exists; the previous transcript feedback fallback remains. This is provider-assisted lesson coaching, not independently validated speech or correctness scoring. Late/mismatched transcription may leave a response ungraded. Provider adherence, audio timing, consent and actual device tests remain release gates. No live provider request or production deploy performed. Unit and prompt isolation tests plus existing build checks.
