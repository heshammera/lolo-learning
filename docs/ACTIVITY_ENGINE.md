# Dynamic activity registry v1
Seven data-only activity contracts have deterministic evaluators and a shared offline form renderer: choice, true/false, multiple choice, sequence, match, integer numeric, classify. Activity IDs and versions, explicit field allowlists, bounded data, strict response checks, curriculum compatibility reports by target activity version and duplicate ID rejection. Unknown types or versions cannot pass compatibility. No HTML or scripts from authored content. Other activity types are explicitly planned, not supported by this registry.
A PIN-protected temporary parent preview renders synthetic draft science examples offline; these do not change grades, progress, or curriculum. Existing 140 lessons and existing activities remain unchanged. This is not yet CMS, a server publication guard, an educator-approved science curriculum, or dynamic delivery. Matching and sequence use keyboard-accessible selects rather than drag/drop. Offline/Android asset manifest updated. Tests cover all evaluators, unsupported versions, invalid answers, and browser preview.
Next: independent web owner/admin authentication and roles, server-side schema/compatibility validation, CMS draft authoring, review/publication version history and rollback, target-client compatibility, signed/versioned downloadable curricula, all remaining V2 activities and requirements.
