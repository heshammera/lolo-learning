# Dictation v1 candidate
The author sets Arabic or English, short spoken text, and up to eight accepted textual answers including the spoken text. Local deterministic grading only after the renderer receives a completed playback event; this is not proof that a learner heard the audio. Uses only OS voices explicitly marked localService=true; no microphone, network fallback, provider call or recording. No voice available means no score; the library intentionally does not claim guaranteed offline capability. Voice quality, local voice availability, accessibility and Android WebView behavior require actual device tests. Browser tests use simulated voices, not real audio. No publication or production signing key is enabled.
