# Offline manual progress migration
Parent settings now expose a limited text backup of the active local profile. Copy the entire generated JSON into a private location outside the app before removing the app. After installing the new APK, unlock parent settings, paste the text, enter a pseudonym and confirm creating a new local profile. Open the restored profile in the local profile list.
The snapshot contains completed original-curriculum lesson IDs and the learning path only; no PIN, account token, names, detailed scores, extra-curriculum progress or installed packages. It is plaintext, not encrypted or authenticated, and may be edited by a parent; it is not verified mastery evidence. Restore rejects incompatible curriculum versions or invalid fields and never overwrites existing profiles. Only works from the application version containing this feature. Older installed APKs without the feature cannot export by this route. Physical-device migration and clipboard usability must be tested before recommending uninstalling an existing app.
