# Pronunciation assessment staging foundation
Phoneme Score remains planned in the activity catalog. This is server-internal groundwork only, not a working pronunciation engine. The normalized adapter contract requires a curated reference and complete ordered per-phoneme evidence from a future specialist provider. It rejects transcripts, partial coverage, malformed scores and mismatched reference/language. No overall score or mastery claim is produced. A provider, supported locales, child-speech calibration and actual audio integration still require review. Locale values in the contract do not imply provider support.
The staging database receipt is owner-scoped, purpose-limited, expires after 30 days and is revocable. An operator must independently review consent and retain the underlying evidence outside this schema. A parent login or a digest alone does not establish legally valid consent. No public endpoint, microphone permission, audio upload, provider call or production activation is added. Future release must implement verified guardian consent and withdrawal UX, provider data-handling review, audio limits and retention/deletion, quotas, explicit recording, and real device tests. All tests use synthetic data.
