# Evidence-aware adaptive learning
The local parent dashboard selects up to three eligible lessons, due review first, then weaker current-version repetition evidence, consolidation, or new lessons. The new adaptive plan chooses an available authored practice mode (word/image recap, independent visual quiz, or tracing), and shows a training focus label. A strong due review may choose visual practice; weak independent trace/visual results select their own modality, never change repetition scores. No generated questions, unvalidated difficulty changes, IQ or pronunciation claims. Parent authorization and pinned active local profile are checked at launch. Recommendations are read-only and offline-compatible. Explicit version changes reset the skill evidence/streak/review interval before recording new evidence, and out-of-order assessments are ignored. Historical raw test results remain available separately; old curriculum evidence is excluded from recommendations. This is an incremental adaptive practice policy, not a complete per-question adaptive engine. CI pending. No AI API calls or real student records accessed.
