# Private homework image storage — candidate
Internal, disabled-by-default storage for synthetic staging. No HTTP upload endpoint, assignment-authoring UI, student activity contract or teacher access. Only an authenticated owning parent may explicitly confirm a submission to an operator-created active assignment. Accept one bounded PNG/JPEG, decode with Pillow and re-encode to fresh JPEG pixels; discard original bytes, name and metadata. Images are private database bytes, not public URLs. Limit ten active submissions per child, hide expired images after seven days, allow owner deletion, cascade on child deletion. A trusted operator must schedule purge_expired before any real data use; backups and database encryption/retention require separate review. Image pixels may contain identifying information; metadata removal does not anonymize them.
Production prerequisites: authenticated teacher assignment and review authorization, verified guardian consent, upload UI and request size/rate/concurrency limits, malware/image processing isolation and dependency review, encrypted storage and backup policy, removal workflow, real-device testing. The staging flag must remain disabled in production. Homework Upload remains planned in the activity library.

Review extension: internal teacher-session check through a server-configured AdminStore, explicit child/assignment/reviewer grants (operator-only), grant revocation, immutable review per submission with reviewed 0–100 or revise/no score, parent-only feedback. Resubmission is a separate submission. No public endpoints or UI. DB tests use mock admin identity and real family DB; cross-database live authentication, review audit, production access control and actual consent remain open. No scores flow into mastery.

Parent preview: install requirements.txt and requirements-homework-staging.txt in a dedicated virtualenv, provision disposable PostgreSQL using FamilyStore.migrate(), a synthetic @example.test parent, child and active synthetic-* assignment. Explicitly configure LOLO_HOMEWORK_STAGING_DATABASE_URL (not production or admin DSN) and LOLO_HOMEWORK_STORAGE_STAGING=true, then run python staging-homework/serve.py. Loopback only at http://127.0.0.1:4185. No real child data. Host/origin guard, bounded requests, no persistent client session or images. No production route, no actual-device verification. Teacher interface remains pending.
