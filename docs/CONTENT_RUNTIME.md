# Additional curriculum runtime (staging)
PIN-gated local file import, explicit confirmation, pinned build public keys (empty by default), verification before install and again before practice. List installed verified packages; scope selection lesson/unit/curriculum uses generic deterministic renderer without AI calls, with explicit next and hard boundary. Runtime is session-local and does not write old curriculum/mastery/path or cloud snapshots. Package storage is device-wide; current profile checked before parent actions. No automatic start, live download endpoint, real trusted keys, saved practice progress, or publication to students. Do not enable before key provisioning, device tests and delivery approval. Device-local PIN is not strong authentication. Closing parent screen during an already-started atomic install may allow confirmed storage transaction to finish; no UI activation. Tests cover scope/evaluation boundaries; browser verification of default-disabled UI and actual IndexedDB from previous milestone. Full real-device end-to-end import, signed fixture UI tests and progress persistence remain open.
