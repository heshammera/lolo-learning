# Staging parent cloud UI
Three independent flags: LOLO_FAMILY_ENABLED, LOLO_PARENT_CLOUD_UI_ENABLED, LOLO_PROGRESS_SYNC_ENABLED. Keep all false for production; status advertises only enabled features. The protected parent settings panel supports login to an operator-provisioned account, listing and creating synthetic child profiles, explicit logout, and comparison of the active local profile with a selected remote child. Credentials and bearer token remain in memory, cleared when closing/locking the panel, moving to lessons, visibility loss or offline. Clearing the client is not guaranteed server revocation; explicit online logout revokes server session. No automatic requests that transfer progress. First backup requires a preview and explicit checkbox confirming synthetic data and correct profile mapping; existing remote revisions are never overwritten by the UI. No restore, persisted account link, offline queue or background sync yet. Local data stays untouched. Testing uses synthetic accounts/mock responses and no live AI requests. Real child data requires verified consent, privacy review, security review, durable quotas and a configured production database.
