# Offline license contract (test only)
No production keys, routes, trust enrollment, persistence or feature gating. P-256 SHA-256 signatures, raw 64-byte signature across Python/WebCrypto. Test key ID prefix and test audience; verifier requires pinned caller-provided public key, exact account/device/child, expiry <= min(subscription expiry, 30 days), sequence high-water and clock rollback heuristic. Local-only feature identifiers; voice, pronunciation, homework, sync and reports excluded. Device registration currently a random UUID, not cryptographic device proof. Provisional limits Plus 2 / Family 4, earliest registered remain eligible on downgrade. Revocation prevents renewal, not already downloaded offline leases; no remote revocation when disconnected. Clock high-water requires durable trusted storage in later integration, cannot guarantee anti-tampering on rooted devices or when storage is reset. Need device-held key proof/Android Keystore, signed trust distribution, local state management and reconnect revocation, UI and feature gates before production. Synthetic parent accounts only, no Paymob changes. Cross-language test uses ephemeral key, real disposable PostgreSQL, no key committed.
