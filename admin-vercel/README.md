# Separate protected Vercel admin
Dedicated root admin-vercel, no student endpoints or credentials. Use the existing Vercel project lolo-admin with all-deployment authentication. Static shell and API return fail-closed until production-only LOLO_ADMIN_SERVERLESS_ENABLED=true, exact LOLO_ADMIN_ORIGIN, independent LOLO_ADMIN_DATABASE_URL with verified TLS, and LOLO_ADMIN_ENCRYPTION_KEY are supplied privately after schema migration and owner MFA enrollment using admin-src/manage.py. Never copy the student DB. No public migration or owner bootstrap endpoint. Family management, billing, signing/export remain local pilot-only and return 503. CMS uses the canonical validator via bounded isolated QuickJS without host functions. Snapshots checked by node sync.cjs --check; regenerate reviewed snapshots after canonical source changes via node admin-vercel/sync.cjs. No secret values committed. This candidate needs CI and actual protected deployment verification.
